## Description of the failure

### Preconditions

Postgres up; volume already initialized with five `persons_*` tables (pre-Go schema).

### Steps to reproduce

1. Start existing `opn-postgres` without wiping volumes.
2. `SELECT COUNT(*) FROM persons_golang;`

### Expected results

Table exists with the same columns and ~1M seed rows as the other five languages (locked product decision).

### Actual results

`ERROR: relation "persons_golang" does not exist`. Other five tables had 1,000,000 rows.

### Evidence

`docker exec opn-postgres psql …` output in Phase 0 session. Init scripts `01`–`05` do not re-run on existing volumes (documented).

Apply `data/vector-store/migrations/migrate_add_golang.sql` then `seed_golang_only.sql` (COPY `/master_seed.csv`). Do not `docker compose down -v`.
