## Description of the failure

### Preconditions

Restore `OmniTest.Polyglot.Nexus.Api.CSharp.csproj`.

### Steps to reproduce

1. `dotnet build services/grpc-csharp/OmniTest.Polyglot.Nexus.Api.CSharp.csproj`
2. Observe CS0104 on `PersonMapper.cs` lines 16 and 39.

### Expected results

Clean compile; mapper uses domain vs proto types explicitly.

### Actual results

`error CS0104: 'Person' is an ambiguous reference between Domain.Person and Shared.Proto.Person`.
